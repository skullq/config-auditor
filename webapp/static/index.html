전체 항목 표시 중
💡 설정값 비교 방식 (Match Type) 사용법 안내
exists 존재 여부만 검사: 해당 명령어/키가 대상 파일에 존재하면 값과 무관하게 합격 (임의의 값 허용)
exact 정확히 일치: 지정한 값과 반드시 100% 동일해야 합격 (예: 17.12)
contains 키워드 포함 검사: 특정 패턴/단어가 포함되면 합격 (예: *CE1*, 10.68.)
regex 정규표현식 검사: 정규식 패턴과 일치해야 합격 (예: ^CE_, ^.*-CE\d+)
👁️ 최종 골든 템플릿 설정 실시간 미리보기 선택된 블록: 0개 / 항목: 0개

선택된 설정 블록과 세부 항목의 설정값(exists, exact, contains, regex 등)이 실시간으로 합쳐진 최종 템플릿 CLI 결과입니다.

선택된 설정 항목이 여기에 실시간으로 표시됩니다.
